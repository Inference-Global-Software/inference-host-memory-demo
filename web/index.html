A program running in memory this page owns

A WebAssembly program normally brings its own memory. This one is built with Inference's [memory] import = true, so this page creates the memory and hands it over. That lets the page watch the program work: it counts 24 temperature readings into four bands, inside memory the page can see.

Left: the memory

The program's working data, byte by byte. Coloured rows belong to the program; the line under each row says what its bytes mean. Pink means a byte just changed.

Right: the conversation

What the program asked this page for, the readings it was given, and its counters and results, read straight out of the coloured bytes.

Bottom: the contract

The program states exactly the memory it needs. Try handing it a different one: the browser refuses to start it.

    The contract

    The program asks for exactly one 64 KiB page that can never grow ((memory 1 1)), because its stack and its overflow checks were laid out for that. Hand it any other memory and the browser refuses to start it. Each button really tries.
