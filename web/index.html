A program that runs in memory this page owns

    Normally, a program brings its own memory

    A WebAssembly program needs memory to work in, and usually it creates that memory itself when it starts. The web page that runs it has no say in it, and can only look inside afterwards.

    With [memory] import = true, the page brings the memory

    An Inference program built this way asks for its memory instead of creating one. The page creates the memory first and hands it over as it starts the program. The memory belongs to the page from the first moment to the last.

    // what this page does const memory = new WebAssembly.Memory({ initial: 2, maximum: 4 }); await WebAssembly.instantiate(program, { env: { memory }, sensor: { … } });

    In the next steps the program counts 24 temperature readings this page feeds it, sorting each into one of four bands, and you watch it happen inside the page's memory.

    The program works in the page's memory

    The page hands over readings one at a time. The program keeps its four band counters in the page's memory, so the page can read them after every reading, without the program copying anything out.

    The results are read where they are

    When it has counted every reading, the program doesn't send its results back. It tells the page where in the memory it put them, and the page reads them right there.
